# Engineering Calculator Framework

A minimal Python package foundation for the first AI Mechanical Engineer
portfolio project.

Version 0.1 currently provides only a command-line entry point. Engineering
calculators and supporting domain logic will be added in later phases.

## Requirements

- Python 3.11 or newer

## Install for development

From this directory, run:

```powershell
python -m pip install -e ".[dev]"
```

## Run

```powershell
engineering-calculator
```

Alternatively:

```powershell
python -m engineering_calculator
```

## Test

```powershell
python -m pytest
```

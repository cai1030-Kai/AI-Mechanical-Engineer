# Engineering Calculator Framework v0.3.0

## Release summary

Version 0.3.0 adds the Euler Buckling Critical Load Calculator and integrates it
with the Python API, command-line interface, Calculator Catalog, and Calculator
Contract v0.1 canonical result model. The framework now contains four
deterministic mechanics-of-materials and structural-stability calculators.

The Python distribution and framework runtime version are aligned at `0.3.0`.
Individual calculators retain independent behavior versions; the Euler
calculator begins at `0.1.0`.

## New Euler Buckling Critical Load Calculator

The `stability.euler_buckling` calculator determines the ideal elastic critical
load of a slender, straight column about one caller-specified principal axis:

```text
L_eff = K * L
P_cr = pi^2 * E * I / L_eff^2
```

The caller supplies elastic modulus `E`, second moment of area `I`, unsupported
length `L`, and the positive dimensionless effective length factor `K`.

## Supported units

| Quantity | Units |
| --- | --- |
| Elastic modulus | `Pa`, `kPa`, `MPa`, `GPa`, `psi`, `ksi` |
| Second moment of area | `mm^4`, `cm^4`, `m^4`, `in^4` |
| Unsupported length | `mm`, `cm`, `m`, `in` |
| Critical load output | `N`, `kN`, `MN`, `lbf`, `kip` |

Calculations normalize locally to `MPa`, `mm^4`, `mm`, and `N`.

## Python API

```python
from engineering_calculator.calculators.euler_buckling import (
    calculate_euler_buckling,
)

result = calculate_euler_buckling(
    200, "GPa", 8_000_000, "mm^4", 3, "m", 1.0, "kN"
)
```

## CLI integration

```powershell
engineering-calculator euler-buckling --elastic-modulus 200 --elastic-modulus-unit GPa --second-moment 8000000 --second-moment-unit "mm^4" --length 3 --length-unit m --effective-length-factor 1 --output-unit kN
```

Successful execution emits the same canonical JSON content as the Python API.
Invalid arguments and calculation inputs retain the existing argparse error
behavior and nonzero exit code.

## Canonical results and traceability

Euler results include:

- Effective length in canonical `mm`.
- Critical load in canonical `N`.
- Critical load in the requested output unit.
- A statement tying the result to the caller-supplied buckling-axis property.
- Symbolic effective-length and Euler equations.
- Substituted canonical values with traceable precision.
- Assumptions, five mandatory applicability warnings, limitations, and
  engineering references.

## Validation and numerical safety

The calculator rejects missing, Boolean, non-real, non-finite, unsupported,
nonpositive, overflowed, and nonzero-underflowed inputs or results. Controlled
validation covers unit conversion, effective-length multiplication and
squaring, flexural rigidity, the Euler numerator, critical-load division, and
output conversion. Arithmetic overflow is translated into local `ValueError`
behavior rather than escaping as an unclassified exception.

## Engineering scope and limitations

The calculator applies only to ideal elastic Euler buckling of a straight,
slender, constant-section column under concentric compression. The caller must
supply the correct second moment of area and effective length factor.

Version 0.3 does not determine slenderness applicability, yielding, inelastic
buckling, local buckling, torsional or flexural-torsional buckling, section
properties, end conditions, safety factors, allowable loads, or code
compliance. The reported critical load is an ideal theoretical magnitude, not
a design strength.

# Engineering Calculator Framework v0.2.0

## Release summary

Version 0.2.0 adds the Beam Bending Stress Calculator and integrates it with the
existing Python API, command-line interface, and Calculator Contract v0.1
canonical result model. The framework now provides three deterministic
mechanics-of-materials stress calculators.

## New Beam Bending Stress Calculator

The `stress.beam_bending` calculator evaluates signed linear-elastic normal
stress for a straight beam in pure bending about one principal centroidal axis:

```text
σ = My / I
```

The caller supplies the bending moment, distance from the neutral axis, and
section second moment of area. Version 0.2 does not calculate section geometry
or section properties automatically.

## Signed moment behavior

- Positive bending moment produces positive tensile stress.
- Negative bending moment produces negative compressive stress.
- Zero bending moment produces zero stress.
- Zero distance from the neutral axis produces zero stress.

The result includes `tension`, `compression`, or `zero` as its stress state.

## Supported units

| Quantity | Units |
| --- | --- |
| Bending moment | `N·mm`, `N·m`, `lbf·in`, `lbf·ft` |
| Distance from neutral axis | `mm`, `cm`, `m`, `in` |
| Second moment of area | `mm^4`, `cm^4`, `m^4`, `in^4` |
| Stress output | `Pa`, `kPa`, `MPa`, `GPa`, `psi`, `ksi` |

Calculations normalize locally to `N·mm`, `mm`, `mm^4`, and `MPa`.

## CLI integration

The new `beam-bending` subcommand accepts explicit named arguments and emits
canonical JSON:

```powershell
engineering-calculator beam-bending --moment 5000 --moment-unit "N·m" --distance 50 --distance-unit mm --second-moment 8000000 --second-moment-unit "mm^4" --stress-unit MPa
```

Signed and zero moments are preserved. Successful JSON is written to stdout;
invalid inputs produce standardized stderr errors and a nonzero exit code.
JSON serialization remains ASCII-safe for Windows GBK consoles.

## Canonical JSON output

Successful results contain exactly the Calculator Contract v0.1 sections:

- `calculator`
- `inputs`
- `results`
- `governing_equation`
- `assumptions`
- `warnings`
- `limitations`
- `references`

Inputs retain their supplied values and units. Results include signed bending
stress, stress state, and a traceable canonical-unit equation substitution.

## Validation and numerical safety

The calculator rejects missing, non-numeric, Boolean, non-finite, unsupported,
or physically invalid inputs. It validates unit conversions, the `M × y`
numerator, division by `I`, the canonical stress, and output conversion.
Overflow and nonzero underflow are rejected rather than returned as valid
engineering results.

## Engineering warnings

Every result warns that the supplied second moment of area, `I`, and distance
from the neutral axis, `y`, must correspond to the same bending axis and section
orientation. Results also warn that external structural-analysis tools may use
different bending-moment sign conventions.

## Verification summary

The full framework has **176 passing tests**. Beam bending verification covers:

- Independent SI and US customary reference examples
- Reverse verification of the applied moment
- Positive, negative, and zero behavior
- Every accepted input and output unit
- Cross-system unit equivalence
- Canonical schema and JSON serialization
- Missing, invalid, non-finite, overflow, and underflow boundaries
- Deterministic repeated execution
- CLI success and error paths
- Regression coverage for axial stress and shaft torsion

## Known limitations

- Beam bending is limited to straight beams in linear-elastic pure bending about
  one principal centroidal axis.
- The caller must supply compatible `I` and `y` values; the framework does not
  calculate or verify section geometry, centroid, or principal-axis properties.
- Biaxial bending and combined axial, torsional, transverse-shear, or pressure
  loading are outside scope.
- The calculator does not evaluate shear stress, deflection, material strength,
  yielding, factor of safety, fatigue, buckling, or code compliance.
- Results are nominal engineering calculations and do not replace applicable
  standards or qualified engineering review.

# Engineering Calculator Framework v0.1.0

## Release summary

Version 0.1.0 is the first documented milestone of the Engineering Calculator
Framework. It establishes a small, testable foundation for traceable mechanical
engineering calculations through both a Python API and command-line interface.

## Included calculators

- `stress.axial` — signed average axial normal stress and loading state for a
  concentric axial load.
- `stress.shaft_torsion` — polar moment of inertia and maximum elastic
  torsional shear stress for a solid circular shaft under pure torque.

See the [Calculator Catalog](../calculator-catalog.md) for concise scope and
specification links.

## CLI capabilities

The `engineering-calculator` command provides two subcommands:

- `axial-stress`
- `shaft-torsion`

Both accept explicit values and units, support selectable stress output units,
and emit canonical JSON. The same interface is available through
`python -m engineering_calculator`.

## Calculator Contract v0.1

[Calculator Contract v0.1](../architecture/calculator-contract.md) defines the
shared calculator metadata, input validation, deterministic execution, error
behavior, and canonical result schema. Successful results include calculator
identity, original inputs, named results, governing-equation traceability,
assumptions, warnings, limitations, and engineering references.

## Unit handling

Version 0.1 uses explicit unit allowlists rather than guessing units. Supported
inputs cover SI and US customary force, torque, area, and length units. Stress
results can be requested in `Pa`, `kPa`, `MPa`, `GPa`, `psi`, or `ksi`.
Calculations normalize to documented internal units before evaluating the
governing equations.

## Validation and deterministic output

Calculators reject missing, unsupported, non-real, non-finite, or physically
invalid inputs. Intermediate and final values are checked for finite results.
No network access, generative model, random state, or mutable external state is
used. Identical inputs and calculator versions therefore produce the same
canonical JSON content.

## Automated verification

The milestone has **97 passing tests**. Coverage includes verified SI and US
customary examples, unit equivalence, sign and zero-load behavior, validation
boundaries, canonical schema content, JSON serialization, deterministic repeat
execution, CLI dispatch, and CLI error reporting.

## Known limitations

- The framework includes only two stress-analysis calculators.
- Axial stress is an average nominal stress and does not assess eccentric
  bending, buckling, local stress concentration, or material failure.
- Shaft torsion applies only to solid circular shafts under pure torque and does
  not assess hollow or noncircular sections, stress concentration, combined
  loading, angle of twist, or failure.
- Neither calculator performs code compliance, fatigue, fracture, material
  strength, allowable-stress, or factor-of-safety checks.
- Version 0.1 uses calculator-specific explicit unit conversions rather than a
  general dimensional-analysis system.
